# Money Machine Files — production runbook (for Claude)

Channel: Money Machine Files (@MoneyMachineFilesHQ), YouTube only. Long-form business
documentaries: "how company X really makes money". English narration, ~8–11 min.
Owner talks Roman Urdu; videos are English.

## Hard rules
- No companies whose core business is riba/interest (banks, lenders, credit cards), alcohol, gambling, tobacco.
- Every number must come from a web search done in this run (company annual report / official results first).
  Paraphrase, never copy sentences. Put "Sources: ..." (names, not URLs) in the description.
- Voice: free Microsoft Andrew neural voice (edge-tts, rate +6%). No paid tools, no stock footage, no real-people photos, no logos.
- Visuals only from mmf/kit/visuals.py (code-drawn). Music is generated by kit/music.py.
- Never commit secrets. `*.mp4` is git-ignored; force-add only the file being uploaded, delete it after upload.

## One episode = one run
1. `cd mmf && python3 next.py` prints the next queue item with status "todo" (slug, company, publish_at,
   short dates). Mark it "doing" in queue.json and push right away (avoids two runs taking the same item).
2. Research (8–15 web searches): founding story, business model, revenue split, latest-year figures,
   one surprising "secret" angle. Write `mmf/episodes/<slug>/scenes.py` (35–45 scenes, ~1400–1700 words)
   following ep01-ikea/scenes.py: cold open (big number + question + ("brand","FILE #0NN  ·  NAME")),
   5–6 chapters (("chapter","N","Title")), outro ("machine" or "list" recap), ("quote", ...), ("end",).
   Visual types: title, quote, brand, chapter, timeline, acronym*, boycott*, flatpack*, list, stat, maze*,
   compare, flow, bars, pie, ownership*, split, machine*, end.  (*IKEA-specific art: don't reuse; if you
   need a custom picture, add a new v_ function to visuals.py + ANIM entry, keep the same palette.)
   `machine` has hard-coded IKEA text — for a recap use `list` instead.
3. Write `mmf/episodes/<slug>/meta.json`:
   {"title": "...", "description": "...{CHAPTERS}...", "tags": [...], "publish_at": "<from queue>",
    "thumb": {"l1": "HOW X", "l2": "REALLY", "l3": "MAKES MONEY", "badge": "SHORT HOOK", "symbol": "$"},
    "shorts": [{"scenes": [i, j, ...], "top": ["LINE1", "LINE2", "LINE3"], "title": "... #shorts",
                "description": "...", "publish_at": "<from queue>"}, {...}]}
   Two shorts per episode, each 35–58 s of consecutive-ish scenes that work alone (check durations after voice).
4. Build: `cd mmf/episodes/<slug> && python3 ../../kit/build.py` (needs `pip install edge-tts --break-system-packages`).
   Look at out/check*.png (Read tool) and one frame of each short. Fix overlaps and rebuild only changed scenes
   (delete vid/sNN.mp4 for those).
5. Upload with Zapier YouTube "Upload Video" (selected_api YouTubeV4CLIAPI, tool youtube_upload_video),
   connection_id `023660ab-5fa1-861f-ba28-80d0e01e0df9` (= Money Machine Files; verify title once with
   GET channels?mine=true if unsure). Host the file first: copy to `mmf/up/`, `git add -f`, commit, push,
   use https://raw.githubusercontent.com/utsyehai5-dot/inside60-videos/main/mmf/up/<file>.
   Params: privacy_status "private", publish_at (UTC Z), made_for_kids false, category_id "27",
   default_language "en", default_audio_language "en", tags, description (replace {CHAPTERS} with out/chapters.txt).
   Long video: also pass thumbnail = raw URL of the _thumb.png (if it errors, retry without thumbnail and note it).
   Shorts: description must include the long video's link https://youtu.be/<id from the long upload>.
6. After all three uploads: `git rm` the files in mmf/up/, set queue item status "done" with video ids, push.
   Commit only scenes.py, meta.json, queue.json and kit changes (never out/, audio/, vid/).
7. Zapier tasks: each upload call costs 2 tasks. Don't make other Zapier calls unless needed.
